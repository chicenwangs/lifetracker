## Bugs found (not fixed; docs-only pass)

1. **Keep note Restore from Trash returns 404.**
   - UI: `/keep?scope=trash` → Restore → toast "Not found".
   - API: `PATCH /api/keep/notes/kn_… {"trashed":false}` → `404 {"error":{"code":"not_found"}}`.
   - Cause: `lib/server/repo/shares.ts` `level()` returns null when `deleted_at` is set, and `PATCH /api/keep/notes/[id]` calls `need('note', …)` first. Trashed notes can therefore never be restored. Blocks and pages use their own restore paths and work.
   - Note: "Delete forever" on the same screen works (DELETE requires `trashed:true`, then succeeds).
2. **`/pages/graph` throws `Sigma: Container has no width`** (unhandled promise rejection, dev console) when opened at phone width. Graph still paints.
3. **Desktop key hints inside the Android app**: header buttons expose `Search Ctrl+K` and `+ Add N`. UX-AUDIT #22 copy rule ("no Ctrl/PC wording on phone") is not applied to the native shell.
4. **Midnight-boundary e2e flake** in the theme test (see Results).
5. **Dev + service worker can serve a stale cached page** when the dev server stops (old rows, dead hydration). Judge offline behaviour on a built server, not `vite dev`.
