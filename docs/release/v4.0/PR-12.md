# PR 12 — daily digest

- **User:** Settings › Notifications has a `Daily agenda` row: `Off | On` plus a time (default 07:30) and a live line "3 items · 2 blocks · first 09:00". On = one notification a day (web push, and an exact alarm in the Android app) with today's own items and planner blocks — counts and the first time only. Nothing planned → no notification. Turning the "Planner items and blocks" reminders off also silences the digest. The preview never shows titles.
- **Files:** `app/src/lib/server/digest.ts` (text, next local time, due list + per-day dedupe in `app_meta`) · `app/src/lib/server/jobs.ts` (tick sends one push per user per local day) · `app/src/lib/server/native.ts` (`digest: { at, text }` for the app) · `app/src/lib/server/repo/users.ts` + `app/src/app.d.ts` (digestTime on the safe user) · `app/src/routes/api/me/prefs/+server.ts` (HH:MM or null, .strict) · `app/src/routes/settings/notifications/+page.{server.ts,svelte}` (row, time, preview, 48 dp on phone) · `mobile/android/.../Reminders.java` (`scheduleDigest`, one fixed-request-code exact alarm, notification with counts, opens /today) · `mobile/android/.../SyncWorker.java` (re-schedules on every sync; boot resyncs).
- **Tests:** unit `tests/unit/digest.test.ts` — 10 passed (counts + first, no titles; done/hidden/other-day/partner excluded; due before/at/after the local time; dedupe; planner toggle off; empty day marks; next alarm today vs tomorrow across the local midnight; native payload carries `{ at, text }`). E2E `tests/e2e/digest.spec.ts` (desktop) + the new test in `tests/e2e/phone/settings.spec.ts`: Off/On, 07:30 default, time change persists, preview visible, bad `25:00` refused (400), 48 dp on phone.
- **Not run locally:** the Android Java compile (the worktree has no `capacitor-cordova-android-plugins` generated dir; the CI `apk` job builds it). Emulator manual check = W1 (documented in the QA run).
