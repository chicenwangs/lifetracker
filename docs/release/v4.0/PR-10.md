# PR 10 — per-type "Month calendar" switch

- User: Settings › Types has a new **Month calendar** switch for every type (on by default, so nothing changes until
  it is used). Off hides that type on the Month grid only — the desktop Home month and the phone Month (grid count
  and the day agenda). Week, Today, the planner, Slipped, search, ICS and reminders still show it. The switch shows a
  toast ("Month calendar off for Event") with Undo; the PATCH also writes one journal entry per edit.
- Server: `PATCH /api/item-types/:id` accepts `onCalendar` (`.strict()`), returns `{ type, undo }` and journals the
  row (`Edit type "<name>"`). `ItemTypeDTO.onCalendar`.
- Client: `onMonth()` (pure, `$lib/itemtypes.ts`) + `typesState` filtering in `MonthCalendar.svelte` (desktop) and
  `routes/month/+page.svelte` (phone items + blocks). Settings column + helper line under the types table.
- Files: `app/src/lib/types.ts`, `app/src/lib/itemtypes.ts`, `app/src/lib/server/repo/itemtypes.ts`,
  `app/src/routes/api/item-types/[id]/+server.ts`, `app/src/routes/settings/types/+page.svelte`,
  `app/src/lib/components/MonthCalendar.svelte`, `app/src/routes/month/+page.svelte`,
  `app/tests/unit/itemtypes.test.ts`, `app/tests/e2e/month-flag.spec.ts`, `app/tests/e2e/phone/month-flag.spec.ts`.
