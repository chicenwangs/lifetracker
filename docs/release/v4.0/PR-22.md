# PR 22 - page templates

- **User:** page menu -> **Make template** (or **Stop being a template**). The page shows a `--ground` pill "Template - edits don't change pages made from it" and leaves the sidebar tree. Templates are listed in the **New page** menu (desktop) and in the Pages **+** sheet (phone); the menu/sheet always opens, and with no templates it shows "No templates yet. Use the page menu > Make template on any page." Choosing a template creates a normal page titled "Untitled <template name>" with its blocks, database schema and icon (PR 17's copier); edits never touch the other page.
- **Storage:** migration 0012's `pages.is_template`; no new migration. Templates are ordinary pages, so the global search finds them; `tree()` excludes them and a new `templates()` lists them.
- **Access:** toggling is owner-only at **both** entry points: the dedicated `/api/pages/[id]/template` route and the generic PATCH (which otherwise only needs edit). Both are journalled (`Make template` / `Stop being a template`), so Ctrl+Z and the toast Undo flip it back. Creating from a template uses any page the user can read, but the copy is their own at a parent they own (top level by default); a foreign parent is refused.
- **Files:** `app/src/lib/server/repo/pages.ts` (`isTemplate` in the DTO/patch, tree filter, `templates()`) · `app/src/lib/server/repo/page-duplicate.ts` (options: title, chosen parent, template flag) · `app/src/lib/types.ts` (`PageDTO.isTemplate`) · `app/src/routes/api/pages/[id]/template/+server.ts` (toggle, journaled) · `app/src/routes/api/pages/[id]/from-template/+server.ts` (copy, journaled) · `app/src/routes/api/pages/[id]/+server.ts` (owner check for isTemplate in PATCH) · `app/src/routes/pages/+layout.server.ts` (`templates`) · `app/src/routes/pages/+layout.svelte` (New page menu + empty state) · `app/src/lib/components/MobileBar.svelte` (phone Pages + sheet + empty state) · `app/src/lib/components/ActionSheet.svelte` (optional hint) · `app/src/lib/client/newPage.ts` (`createFromTemplate`) · `app/src/routes/pages/[id]/+page.svelte` (menu action + pill).
- **Tests:** unit `tests/unit/page-templates.test.ts` - 5 passed (tree hides + templates lists + search finds; copy content/title/parent and foreign parent refused; owner-only toggle + undo; a shared editor's PATCH isTemplate is 403; from-template route copies and undo removes it). E2E desktop `tests/e2e/page-templates.spec.ts` (empty-state menu -> make template -> leaves tree -> New page > template -> content copied) and phone `tests/e2e/phone/pages.spec.ts` (Pages + sheet -> template -> copy).
