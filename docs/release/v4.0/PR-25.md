# PR 25 — DB gallery view

- A database can have a Gallery view: `+ View` → Gallery. Cards grid: cover (16:9), title, up to 2 property chips (`Card shows`, same picker as the board).
- View settings → `Cover` (a link property; only its picture URLs render, `https://…/pic.png`-style) and `Card size` S / M / L = card width 180 / 240 / 320 px. No cover → `--ground` block. Page cover (PR 31) is not wired yet; the record page icon is not in the db row.
- Click a card = opens the record (creates its page first, same as the board card). Empty gallery = "No records yet." + `New record`.
- Phone: 2 columns for S/M, 1 for L (DESIGN 2.7); cards are ≥ 48 dp; View settings opens in the shared BottomSheet.
- `ViewConfig` gains `coverProp` (a url property, checked in `checkConfig`) and `cardSize` (`S|M|L`); the views route accepts `gallery`; `cloneSchema` remaps `coverProp` to the copied property (`cardSize` is not an id) — unit copies a db whose view holds `sort`, `coverProp` and `cardSize`.
