# PR 11 — import a calendar file (.ics)

- User: **Settings › Import** is now open to everyone and has a **Calendar file (.ics)** card. Pick a file (up to 512 KB) → **Preview** shows "N events · M repeating · K skipped", "Already imported: X will be updated" and a
  **Skipped** list with plain-words reasons → choose **Put them in type** (default: a type with Month calendar off,
  else No type) → **Import**. One toast with Undo for the whole file. Importing the same file again updates the same
  events (matched by UID) instead of copying them;events missing from the new file are left alone. The Notion seed
  import stays admin-only (its action is now `?/notion`).
- Parser (`app/src/lib/server/ics-import.ts`, own, no dependency): VEVENT only — UID, SUMMARY, DTSTART/DTEND,
  RRULE, EXDATE, TZID; folded lines; RFC text escapes; DATE, UTC (`Z`), IANA `TZID` and floating times converted to
  the user's local date/time; all-day DTEND treated as exclusive; timed events across midnight keep the day span.
  Supported RRULE: FREQ (DAILY/WEEKLY/MONTHLY/YEARLY), INTERVAL, BYDAY (incl. `2MO`), BYMONTHDAY, UNTIL, COUNT
  (WKST is dropped only when it cannot change the result). Everything else is skipped and listed, never guessed:
  BYSETPOS/BYWEEKNO/BYYEARDAY/BYMONTH/BY* time parts, hourly/minutely repeats, unknown timezones, modified
  occurrences (RECURRENCE-ID), cancelled events, no UID, no title, > 300-char titles, duration-without-end.
  Limits: 512 KB text (adapter-node's POST body cap; the page refuses a bigger file before the request), 2 000 events, 64 KB per unfolded line, 500 EXDATEs per event, 100 listed skips.
- Server: `items.ics_uid` + `items.exdates` are now valid create/patch fields; `items.byIcsUids()` (owner-scoped,
  my default calendar) matches re-imports. The import runs in one `undoable` entry (inserts + updates); owner
  scoping and `ROW_CAP` come from the repo functions. No outbound calls; only the uploaded file is read.
- Files: `app/src/lib/server/ics-import.ts`, `app/src/lib/server/repo/items.ts`,
  `app/src/routes/settings/import/+page.server.ts`, `app/src/routes/settings/import/+page.svelte`,
