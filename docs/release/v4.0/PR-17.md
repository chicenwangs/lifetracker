# PR 17 — duplicate page

- **User:** page ⋯ → **Duplicate** opens a copy titled "Copy of <title>" right below the original (same parent when it is yours; top level for a shared page), with the same icon and blocks (new block ids). Database blocks copy their **schema** (properties and views) with no records (DESIGN §4.1 default). Child pages are not copied. Shared pages copy into the duplicator's own tree with no shares.
