# Fix #400 — Keep: + in Trash/Archive saves a note that is not shown

- The phone `+` on Keep opens the new-note editor. On `?scope=trash` / `?scope=archive` the saved note landed in Notes while the list kept showing Trash/Archive, so it looked lost.
- Owner decision (a): the `+` switches the view to Notes first. `MobileBar.add()` drops `scope` from the Keep URL before setting `new`; the list reloads on Notes and the saved note is visible.
- Files: `app/src/lib/components/MobileBar.svelte`, `app/tests/e2e/phone/keep.spec.ts`.
- Test: phone `keep.spec.ts` 10 passed, both projects (open `?scope=trash`, tap `+`, URL no longer has `scope=trash`, fill the note, Back, the card is in the list).
