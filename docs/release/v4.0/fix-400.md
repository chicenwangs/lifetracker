# Fix #400 — Keep: + in Trash/Archive saves a note that is not shown

- The phone `+` on Keep opens the new-note editor. On `?scope=trash` / `?scope=archive` / `?scope=shared` the saved note landed in Notes while the list kept showing that scope, so it looked lost.
- Owner decision (a): the `+` switches the view to Notes first. `MobileBar.add()` drops any `scope` (trash, archive, shared - all three can hide a new note) from the Keep URL before setting `new`; the list reloads on Notes and the saved note is visible. A binder filter (`?binder=`) is kept: the page's own New note is visible there and a new note does not auto-join a binder (out of this issue's decision).
- Files: `app/src/lib/components/MobileBar.svelte`, `app/tests/e2e/phone/keep.spec.ts`.
- Test: phone `keep.spec.ts`, both projects (each of trash, archive, shared: open the scope, tap `+`, the URL loses `scope`, fill the note, Back, the list is Notes and the card is there).
