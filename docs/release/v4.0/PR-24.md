# PR 24 — DB calendar view

- A database can have a Calendar view: `+ View` → Calendar. View settings → `Date property` (a date property picks the day a record sits on).
- The month grid (Monday first, `‹` `›` per month) shows each record as a chip with its title on its date. Records with no date wait in the `No date (n)` rail (220 px, desktop). Desktop: clicking a day number creates a new record dated that day; clicking a chip opens the record.
- Phone: one month grid with a dot on days that hold records; tapping a day opens the list under the grid (records + `+ New record` dated that day); the `No date` rail sits below; 48 dp targets.
- Records never appear on the planner calendar — this view is self-contained (DESIGN 2.7).
- No date property → "The calendar needs a date property." + `Add a date property` (opens the add-property panel).
- Also in this PR (LEAD's cross-PR note): `databases.cloneSchema` now remaps the view-config property ids for `groupBy`, `cardProps` (board, PR 23 merged without it) and `dateProp` (calendar), with a unit in `page-duplicate.test.ts` that copies a database holding all three keys.
