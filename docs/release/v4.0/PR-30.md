# PR 30 — reminders on page to-dos

- **User:** put the cursor in a to-do → **Remind me** (desktop block tools; phone block sheet) opens the existing reminder picker. Exact times only (a to-do has no date). A bell chip after the text shows the due time; the chip reopens the picker. Ticking the to-do cancels the reminder (toast "Reminder cancelled · Undo"; Undo un-ticks, and the next save brings it back). Deleting the to-do cancels its reminder on the next save.
- **Storage:** `reminders.source_type = 'page_todo'`, `source_id = pageId:blockId`. Migration 0012 already allows the type; no new migration. The block id is a new `taskItem.blockId` attr (`pbl_` + 16), kept in the saved doc by the extended `TodoItem`; page saves rebuild `page_blocks` rows, so this is what makes a reminder survive.
- **Access:** adding needs `need('page', user, pageId, 'edit')` — owner or editor; viewers and strangers get 404/403. Reminders stay private to whoever set them; `sourceInfo` requires `level('page')` (revoked share / trashed page cancels on the tick). `/api/native` alarms include them, and `notify_pages` is respected like every pages reminder.
- **Files:** `app/src/lib/server/reminders.ts` (source, `pageTodoParts`, `todoIn`, `forPage`, `syncPageTodos`) · `app/src/lib/server/repo/pages.ts` (allow + validate `taskItem.blockId`, sync reminders after a doc save) · `app/src/routes/api/reminders/+server.ts` (`page_todo`, `?page=` chips) · `app/src/lib/editor/extensions.svelte.ts` (`TodoItem`, `TodoIds`, `TodoReminders` decoration) · `app/src/lib/editor/PageEditor.svelte` (Remind me, picker, chip, tick toast/Undo) · `app/src/lib/components/Reminders.svelte` (source union) · `app/src/routes/pages/[id]/+page.svelte` (pass tz).
- **Tests:** unit `tests/unit/page-todo-reminders.test.ts` — 3 passed (add + tick cancels; un-tick restores, delete cancels; stranger/viewer refused, editor allowed, reminders private). E2E desktop `tests/e2e/page-todo-reminders.spec.ts` (set → list → close → chip → tick toast) passed; phone `tests/e2e/phone/pages.spec.ts` "to-do reminder from the block sheet" passed.
