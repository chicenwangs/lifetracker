# PR 31 - page cover image

- **User:** page menu -> **Add cover...** opens a picker: upload a PNG/JPEG/GIF/WebP, or choose one of the page owner's ready images. The banner is **180 px** on desktop and **120 px** on a phone; hovering it (always visible on phone) gives **Change cover** and **Remove**. The toast Undo restores the previous cover. The cover is served to everyone who can open the page, and a `page_cover` reference keeps it from the 7-day orphan purge.
- **Undo:** a cover-only PATCH is journalled (label "Page cover" / "Cover removed", page row target). Undo restores the old `cover_attachment_id`, and `undo.ts` re-syncs the `page_cover` ref (a side table) in the same transaction. Deleting a page while undoing a creation also drops its `page_cover` refs.
- **Files:** `app/src/lib/server/repo/pages.ts` (`patchSchema.coverAttachmentId`, owner + ready check, `page_cover` ref sync, `get()`, purge drop) · `app/src/lib/server/attachments.ts` (`ownedReady`, `images`, `page_cover` maps to page access for readers) · `app/src/lib/types.ts` (`PageDTO.coverAttachmentId`) · `app/src/routes/api/pages/[id]/+server.ts` (journalled cover PATCH) · `app/src/routes/api/attachments/+server.ts` (`?list=images`) · `app/src/routes/pages/[id]/+page.svelte` (banner, picker with upload + ready images, Change/Remove, toast Undo) · `app/src/lib/server/undo.ts` (cover ref sync + created-page cleanup).
- **Tests:** unit `tests/unit/page-cover.test.ts` - 5 passed (set/ref/remove; another user's file refused; the ref keeps the file through `gc` and removing the cover lets it go; a cover-only PATCH is journalled and undo restores the cover + ref; undoing a created page drops its ref). E2E desktop `tests/e2e/page-cover.spec.ts` (Add cover picker, upload, banner + fetch 200, reload keeps it, upload change, pick the existing image, remove -> Undo) passed. Phone `tests/e2e/phone/pages.spec.ts` cover test asserts the 120 px banner; the whole file passed.
- **Backups:** `docs/SERVICE-HANDOFF.md` already states `data/uploads/` is backed up with the DB (v2 `backup.sh` writes `uploads-<ts>.tar.gz`); the cover is an ordinary attachment there, so no doc change.
