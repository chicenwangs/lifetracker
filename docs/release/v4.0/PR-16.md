# PR 16 — page emoji icon

- User: a page can carry an emoji. **Desktop**: 56 px icon above the title; while empty, a faint 13 px `☺ Add icon`
  hover row sits there, and a click opens a 320 px popover (8 × 5 of the exact DESIGN 2.2 curated 40, 36 px cells,
  Remove top-right). Arrows move, Enter picks, Esc closes from anywhere inside (grid, Remove) and focus returns to
  the button. **Phone**: 44 px visual icon in a 48 dp tap box (repo phone hit rule), the empty page has no header row
  — `⋯` › `Add icon` opens the same grid in a BottomSheet (6 columns, 48 dp cells). The icon shows in the sidebar
  tree, page header, `[[` link picker, graph list + "Linked from" panel and the graph node label.
- Undo: `PATCH /api/pages/:id {icon}` is journalled (icon-only changes only, so title/doc autosave never floods the
  journal); the toast Undo and Ctrl+Z both restore the old icon (none = no icon). The journal now ignores
  `pages.last_opened_at` when checking "changed since": every page load stamps it, which used to make an icon undo
  fail with "Can't undo safely" right after opening the page (unit test added).
- Phone layout: pages layout now stretches its column on phone (`align-items: stretch`); the icon + title row was
  wide enough to push the whole page sideways (451 px in a 412 px viewport), which also pushed the docked editor
  toolbar off screen.

  labels, PATCH route, `lib/server/undo.ts`, `routes/pages/+layout.svelte`.
- Tests: desktop `flow.spec.ts` "v4 PR 16": keyboard-pick ✅ → trigger + sidebar show it → toast Undo clears it →
  set again → Shift+Tab to Remove, Esc closes and returns focus → graph list shows it; 49 passed (3.7m) for the
