# PR 16 — page emoji icon

- User: a page can carry an emoji. The button left of the title shows the icon, or a faint "Add icon". Desktop: a
  320 px popover, 8 × 5 curated emoji, Remove top-right; arrows move, Enter picks, Esc closes, focus goes back to
  the button. Phone: the same grid in a BottomSheet, 6 columns of 48 dp cells, Back closes it. The icon then shows
  in the sidebar tree, the page header, the `[[` link picker, the graph list + "Linked from" panel and the graph
  node label.
- Undo: `PATCH /api/pages/:id {icon}` is journalled (icon-only changes only, so title/doc autosave never floods the
  journal); the toast Undo and Ctrl+Z both restore the old icon (none = no icon). The journal now ignores
  `pages.last_opened_at` when checking "changed since": every page load stamps it, which used to make an icon undo
  fail with "Can't undo safely" right after opening the page (unit test added).
- Phone layout: pages layout now stretches its column on phone (`align-items: stretch`); the new icon + title row
  was wide enough to push the whole page sideways (451 px in a 412 px viewport), which also pushed the docked
  editor toolbar off screen.
- Files: `app/src/lib/components/PageIcon.svelte` (new; curated set, popover + sheet, keyboard), page header
  (`routes/pages/[id]/+page.svelte`), link picker (`lib/editor/PageEditor.svelte`), `repo/pages.ts` `findByTitle`,
  `graph.ts` + `GraphDTO` + graph page labels, PATCH route, `lib/server/undo.ts`, `routes/pages/+layout.svelte`.
- Tests: desktop `flow.spec.ts` "v4 PR 16": keyboard-pick 📕 → trigger + sidebar show it → toast Undo clears it →
  set again → graph list shows it — 49 passed (2.7m) for the whole flow file. Phone `pages.spec.ts`: sheet opens,
  48 dp, Back closes it, Remove clears it — 16 passed (32.7s) across phone + phone-landscape. Unit 469 passed,
  1 skipped · lint + check clean.
