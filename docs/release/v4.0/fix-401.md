# Fix #401 — Pick date with an invalid date says why

- **User:** Phone reschedule → "Pick date…": typing something that is not a date (e.g. `nope`) now leaves the dialog open with an inline red message "Use a real date in YYYY-MM-DD form, for example 2026-12-03." instead of closing silently. A real date still moves the item with Undo.
- **Files:** `app/src/lib/client/dialog.svelte.ts` (text dialogs accept an optional `check` validator) · `app/src/lib/components/Dialog.svelte` (shows the message inline in a `role=alert`, stays open) · `app/src/lib/client/reschedule.ts` (`pick()` uses the validator).
- **Tests:** phone e2e `tests/e2e/phone/reschedule.spec.ts` — invalid date: dialog visible + alert text + item unchanged; valid date: moved, Undo puts it back.
- **Docs to change:** none (error state is DESIGN §3 "` .alert ` inline").
