# PR 21 — Local graph (2-hop)

- Page `⋯` → `Local graph` opens the graph around this page: a 900×640 dialog on desktop, full screen on the phone. Top bar: "Links around <page>", `Depth 1 | 2` segmented, the page count, `Open full graph` and Close.
- Nodes: this page big in `--ink`, 1-hop medium, 2-hop small and faded (archived greyed, record pages tinted); label = icon + title. Tap a page opens it. No links yet → one short hint line.
- Server: `localGraph(viewer, aroundId, depth)` walks `page_links` in both directions from the page, then adds parent/child edges among the pages that end up in the set. **Every candidate is checked with `accessOf('page', viewer, id)`**: a page the viewer cannot open is never a node, id, title or count; the around page itself must be viewable (404 otherwise). Cap 250 nodes per local graph (`LOCAL_MAX`), `truncated` reported.
- API: `GET /api/graph?around=<pageId>&depth=1|2` (no params = the whole graph as before), private, no-store.
- Known issue 2 fixed: Sigma is created only after the container has a real size (waits on `clientWidth` + `resize()`), so the "Container has no width" console error is gone; the e2e asserts no page errors or console errors on the phone.
- Back: the dialog is a query state (`?lg=1`) opened with `goto`, so one Back closes it and stays on the page (the page menu's own Back entry is left with `leave()` first so it cannot pop the dialog's). This replaces `use:backCloses` for this dialog: same user-visible contract, one history entry, no menu→dialog layer race (the layer swap lost the entry in phone tests).
- Files: `app/src/lib/server/graph.ts` (localGraph + icons in nodes), `app/src/lib/types.ts` (`GraphDTO` icon), `app/src/routes/api/graph/+server.ts` (`around`/`depth`), `app/src/lib/components/LocalGraph.svelte` (new), `app/src/routes/pages/[id]/+page.svelte` (menu item + dialog), `app/tests/unit/graph.test.ts`, `app/tests/e2e/flow.spec.ts`, `app/tests/e2e/phone/pages.spec.ts`.
- Tests: lint, svelte-check, unit (local depth 1 vs 2, parent edges, access filter drops the unshared 2-hop page and its id, 404 for a page the viewer cannot open), desktop `flow.spec.ts` 49 passed (local graph test: opens, depth 1/2 counts, no console errors), phone `pages.spec.ts` 18 passed (full-screen, Back closes and stays, no console errors).
- Doc lines to change: `docs/v4/DESIGN.md` §2.10 (dialog, depth, open full graph) matches; the Back entry is a URL entry instead of `use:backCloses` (behaviour identical).
- Review round (W5): draw() has a generation token so a fast Depth 1 then 2 (or a slow first response) can never let an older response assign Sigma/counts over a newer one; only the winning draw kills/creates Sigma. Record pages are tinted like the full graph (kind = record).
