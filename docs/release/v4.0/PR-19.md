# PR 19 — `[[` page link picker

- User: typing `[[` in a page opens the link picker at the caret, anywhere in a line (also mid-sentence). Empty query
  shows **Recent** (the 10 most recently opened pages, icon + title + parent page; with no recents yet it says
  "Type to search or create a page"); typing shows **Pages** matches with the query bolded, archived marked, and
  always a last row `+ Create page "<query>"`. Arrow keys move, Enter links, Esc leaves the typed `[[text` as plain
  text. A page link is the existing page-link chip (`↗ title`), so the links projection and graph pick it up
  unchanged. The `/` menu's "Link to page" now just types `[[` and opens the same picker (the old centre dialog is
  deleted). The desktop popover is clamped to the viewport (width = min(320, innerWidth − 24), left ≥ 12), like
  #403.
- Create page: creates a child of the current page, links it, toasts `Created "<title>"`. One Undo removes the page
  (journal) **and** the chip: the undo finds the `pageLink` node by page id in the current doc, so typing after the
  create does not matter (e2e types a character first, then Undo → chip gone, page 404). New page buttons also get a
  journal entry (`POST /api/pages` is journalled now).
- Phone: the picker is a BottomSheet docked above the keyboard, 5 rows visible, 48 dp, no footer hint; the editor
  keeps focus so typing continues. Back/Close closes it.
- Files: `lib/editor/MentionMenu.svelte` (new), `extensions.svelte.ts` (shared Suggestion render + `Mention`
  extension; one plugin key each; `allowSpaces` + `allowedPrefixes: null`), `PageEditor.svelte`, `SlashMenu.svelte`,
  `BottomSheet.svelte` (`keepFocus`), `repo/pages.ts` (`recent`/`findByTitle` + icon + parent title),
  `api/pages/find` (empty q = recent 10), `api/pages` POST (journalled).
- Tests: desktop `flow.spec.ts` P3 link step updated; PR 19 test (Recent header, Pages matches, arrows + Enter,
  create-new → type → toast Undo removes chip + page 404, Esc keeps text, narrow-window clamp) — 49 passed (3.6m).
  Phone `pages.spec.ts` new test (sheet, focus stays, 48 dp, no footer hint, Back closes, Enter links) — 16 passed
  (41.2s) phone + phone-landscape. Unit 469 passed, 1 skipped · lint + check clean.
- Docs to change later: none (BREAKDOWN/DESIGN already describe it).
