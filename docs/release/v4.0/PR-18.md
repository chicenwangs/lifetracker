# PR 18 — callout, toggle, table of contents

- **Callout** (`/callout` → “Highlight a note”): rounded 10 px box, 3 px left bar and pastel background in the four
  DESIGN tones (grey/blue/yellow/red, light + dark pairs), holds paragraphs and lists. The emoji sits top-left and
  opens the PR 16 picker (compact 24 px button / 48 dp phone, same popover/sheet); four tone swatches change the tone
  (visible on hover/focus, always on phone). Old clients and HTML get a `blockquote[data-callout]`.
- **Toggle** (`/toggle` → “Hide details under a line”): the first block is the summary, the rest is hidden when
  closed. `open` is saved in the JSON; the chevron (24 px desktop / 48 dp phone) toggles; Enter on the summary opens
  a closed toggle (when open, Enter edits normally); empty body shows the “Empty toggle. Type or drop blocks inside.”
  hint. Old clients/HTML get `<details><summary>`.
- **TOC** (`/toc` → “List this page's headings”): read-only box (`--ground`) titled “On this page”, H1–H3 indented
  0/16/32 px, rebuilt on every doc change, click scrolls the heading into view; no headings → “Add headings to fill
  this”.
- Slash menu carries the three entries with the DESIGN hint text. The tone swatches live in the callout itself on this
  branch; PR 29 adds the block `⋮⋮` → `Colour ▸` path once both merge (noted for the merge).
