# PR 9 — repeat from completion

- **User:** in an item's Repeat box (daily / weekly / monthly without weekdays or an end date) a new row `Next one counts from` offers `Scheduled date` (default) or `When I finish it`, with the line "Every N days, counted from when you finish". A from-completion series shows **only its next date** in every view and widget (no future ghosts; a small ↻✓ marks the row). Ticking it Done leaves a done copy on today as history and moves the series to today + the interval; one Undo restores the old date and removes the copy. An overdue from-completion series appears in Slipped. The calendar feed exports it as one event without a repeat rule. Rules with an end (UNTIL/COUNT) stay scheduled repeats: the radio is hidden and the API refuses the flag.
