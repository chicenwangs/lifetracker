# PR 20 — Linked from (backlinks panel)

- Under the editor every page shows `Linked from (n)`: one row per page that links here, with the source icon, its title (a link) and a one-line snippet of the linking block (the link text to this page is bold, cut at 120 chars).
- Open by default for 1–5 sources, collapsed above 5; the whole panel is hidden when nothing links here. The heading button toggles it.
- Archived sources stay, greyed with "· archived". Trashed sources and pages the viewer cannot open are dropped **server-side**: `pagesRepo.backlinks(viewer, pageId)` walks the `page_links` projection and checks every source with `level('page', viewer, id)` before it is returned (PLAN §5.4).
- Review round (W5): a snippet's own internal links are filtered with the same access check — a link to a page the viewer cannot open shows the editor's "Unavailable page" label, never its title; titles are cached per call (one SELECT per unique page, not per link). Unit: A (shared with the viewer) links to B and to a private C; B's Linked from shows A, and the snippet shows C as unavailable.
- Files: `app/src/lib/server/repo/pages.ts` (backlinks + snippet builder), `app/src/routes/pages/[id]/+page.server.ts` (loads them for the viewer), `app/src/routes/pages/[id]/+page.svelte` (panel), `app/src/lib/types.ts` (`BacklinkDTO`), `app/tests/unit/pages.test.ts`, `app/tests/e2e/flow.spec.ts`, `app/tests/e2e/phone/pages.spec.ts`.
- Tests: lint, svelte-check, unit (access filter: shared source shown, private source dropped; snippet link to a private page is "Unavailable page"; archived kept, trashed gone; target link bold), desktop `flow.spec.ts` (link A → B, open B, see A; collapse/expand; hidden when none), phone `pages.spec.ts` (panel + 48 dp row).
