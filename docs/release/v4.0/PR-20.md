# PR 20 — Linked from (backlinks panel)

- Under the editor every page shows `Linked from (n)`: one row per page that links here, with the source icon, its title (a link) and a one-line snippet of the linking block (the link text to this page is bold, cut at 120 chars).
- Open by default for 1–5 sources, collapsed above 5; the whole panel is hidden when nothing links here. The heading button toggles it.
- Archived sources stay, greyed with "· archived". Trashed sources and pages the viewer cannot open are dropped **server-side**: `pagesRepo.backlinks(viewer, pageId)` walks the `page_links` projection and checks every source with `level('page', viewer, id)` before it is returned (PLAN §5.4 — a private page linking to something I can open never leaks its title).
- Files: `app/src/lib/server/repo/pages.ts` (backlinks + snippet builder), `app/src/routes/pages/[id]/+page.server.ts` (loads them for the viewer), `app/src/routes/pages/[id]/+page.svelte` (panel), `app/src/lib/types.ts` (`BacklinkDTO`), `app/tests/unit/pages.test.ts`, `app/tests/e2e/flow.spec.ts`, `app/tests/e2e/phone/pages.spec.ts`.
- Tests: lint, svelte-check, unit 470 (new: access filter — a source shared with the partner appears, a private one is dropped; archived kept, trashed gone; snippet bold), desktop `flow.spec.ts` (link A → B, open B, see A; collapse/expand; hidden when none), phone `pages.spec.ts` (panel + 48 dp row).
