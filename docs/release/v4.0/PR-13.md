# PR 13 — voice note (Android)

- The Keep quick-note composer in the Android app gets a 48 dp mic button right of the note field. Tap it once: a short rationale sheet ("Use the microphone?" — Not now / Continue), then the phone's microphone permission. Speak and the words appear at the cursor; the button pulses and the placeholder reads "Listening…" while it listens. Tap again to stop.
- Speech recognition prefers the on-device recognizer (`EXTRA_PREFER_OFFLINE`); the app stores no audio. If the permission is denied the mic is greyed and a tap says how to turn it on in Android settings.
- Web: no button (the browser has no local recognizer in this design).
- **New Android permission: `RECORD_AUDIO`** — the APK asks for the microphone at runtime; release notes must name it.
- Files: `mobile/android/app/src/main/java/io/github/chicenwangs/lifetracker/SpeechPlugin.java` (new; `Speech.listen`/`stop`), `MainActivity.java` (register), `AndroidManifest.xml` (RECORD_AUDIO + `<queries>` for `android.speech.RecognitionService`), `app/src/lib/client/native.ts` (`speech()`, `hasSpeech()`), `app/src/lib/components/MobileAdd.svelte` (mic, rationale sheet, insert at cursor), `app/tests/unit/native-speech.test.ts`, `app/tests/e2e/phone/plus.spec.ts`.
